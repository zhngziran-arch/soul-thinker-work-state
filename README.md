# Soul Thinker · 上班状态测试

Soul Thinker 的免费上班状态测试。按日常工作体验作答，看看这份工作哪里还算舒服、哪里已经让自己吃不消。结果不会推算“离职概率”。

## 现在的体验

- 24 道情境题，从电量、边界、掌控、关系、回报、成长六个综合维度描绘日常工作感受。
- 根据最低的面向出现一道不同的追问，再问一项用户最想保住的东西。总共 26 题。
- 结果由三组状态组合成八种标题，配合六轴图、用户在意的事，以及与具体回答相连的小建议。
- 可生成带六项分数的分享卡；填写称呼后会显示在图上。答题和计算都在浏览器本地完成，可从页脚清除记录。

题目和规则由作者自编，尚未做心理测量学验证。它适合自我梳理，不是诊断、人格定义或职业建议。题目中出现明显身体不适、不安全的人际关系、长期未兑现的待遇时，结果页会额外提示寻求支持。

## 本地开发

需要 Node.js 22 和 npm。

```sh
npm ci
npm run dev
```

运行 `npm test` 和 `npm run build` 验证，构建产物位于 `dist/`。这是纯静态站点，目前无需后端或账号。部署前请自行确认微信平台对外部网页、公众号菜单和小程序跳转的当前要求。

## 代码位置

- `src/data/quizData.js`：题目、维度和自适应追问
- `src/utils/calculator.js`：分数、状态和具体反馈
- `src/utils/storage.js`：当前浏览器中的草稿
- `src/components/ResultScreen.vue`：结果页
- `src/components/SharePosterModal.vue`：分享卡
- `tests/calculator.test.js`：关键计算与存储检查

品牌名称与 `public/soul-thinker-logo-transparent.png` 属于非典型思考者的品牌素材。仓库目前没有附带开源许可证；若要向公众开放复用，需由作者另外明确代码与品牌素材的许可范围。
